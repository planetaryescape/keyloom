# S19: the Anthropic adapter through OpenRouter

Run 2026-10-15 on `rung10/providers` from `0e04ffb`, with BK's OpenRouter key from 1Password (never printed or stored). Raw logs are in `.orchestrate/keyloom-2026-10-15/evidence/rung10/`.

## What was run

`KEYLOOM_EVAL_PROVIDER=openrouter KEYLOOM_LIVE_EVALS=1 bun test evals/scenarios/option-option.eval.test.ts`, which builds the model through the same factory the app uses: `new Anthropic({ apiKey: null, authToken, baseURL: "https://openrouter.ai/api" })` and `anthropic/claude-opus-5.5` at effort medium.

## Results

| Question | Result |
|---|---|
| Does the Tool Runner loop work through OpenRouter? | Yes. Two turns, five model requests, a valid `propose_changes` call. The eval's three checks passed. |
| Streaming, adaptive thinking and `output_config.effort`? | Accepted unchanged. |
| `cache_control: { type: "ephemeral" }`? | Accepted, and it works: 111,447 cache-read tokens and 33,971 cache-write tokens over the run. |
| The fallback beta (`betas: ["server-side-fallback-2026-07-01"]`, `fallbacks: "default"`)? | Rejected, so it is dropped for OpenRouter only. The first run failed with HTTP 400 `Invalid Anthropic Messages API request`, `path: ["fallbacks"]`, `Invalid input: expected array, received string`. OpenRouter validates `fallbacks` as an array. The direct Anthropic path keeps it. Whether OpenRouter accepts an array of fallback models was not tried: its own routing covers that need. |
| `usage.cost`? | Present, but only on the closing `message_delta` event (`"cost":0.00019008,"is_byok":false,"cost_details":{...}`). The SDK's final message keeps only the usage fields it models, so the adapter reads `cost` from the `streamEvent` and sums it over the requests in a turn. A one-request call to `anthropic/claude-sonnet-5.5` returned `costUsd` 0.00016236. |
| Out-of-credits error? | Not triggered: BK's OpenRouter account has credit. The classifier treats HTTP 402 (OpenRouter's documented "Insufficient credits") and Anthropic's 400 "credit balance is too low" as `no_credits`. Both are tested against scripted responses, not the live services. |
| Model IDs | `anthropic/claude-opus-5.5` and `anthropic/claude-sonnet-5.5` are in OpenRouter's live `/api/v1/models` list. |

## Cost

The first passing run, before the adapter read `usage.cost`, reported a table estimate of $0.260. After it did, the four evals on OpenRouter reported $0.255 (option-option), $0.304 (command-shift), $0.182 (remembered-reason) and $0.300 (do-that-here, both boards), $1.041 in all, and one compiled-binary chat reported $0.107. OpenRouter's `/api/v1/credits` and `/api/v1/key` totals did not move in the minutes after the runs (`total_usage` 931.349 before and after), so the account-side balance could not be used to cross-check these figures.
